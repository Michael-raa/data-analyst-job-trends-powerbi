# 📈 Global Data Analyst Job Trends (Power BI)

## 📌 Project Overview
This project explores the current landscape of the data profession. I designed an interactive Power BI dashboard to visualize core industry metrics, helping aspiring data professionals understand market demands and compensation expectations.

## 🛠️ Tools & Technologies
* **Power BI:** Data visualization, interactive dashboarding, and metric tracking.
* **Excel:** Raw dataset storage and initial formatting.

## 📊 Key Business Insights
* **Compensation Analysis:** Visualized average salary distributions across various global data roles.
* **Skill Demand:** Ranked the most in-demand programming languages and technical tools requested by employers.
* **Industry Sentiment:** Analyzed overall job satisfaction metrics across different analyst positions.
